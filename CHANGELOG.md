# Changelog

## Unreleased — first public release (source-available)

Refactor of the research code that produced the (revised) paper results into an installable,
tested package. **Numerics follow the revised research code** (`genspwd`, r5 results):
`tests/golden/golden_v1.npz` was generated by that code (`scripts/make_golden.py`) and the test
suite checks that the package reproduces its scenes, noisy signals, SRFs, dictionaries, OMP
supports and all metrics.

### Faithful to the paper (deliberately unchanged)
- Metrics: `ECM = 1 - M/N` (positive = under-estimation), and detection scores with
  `FP = M - TP`, `FN = max(0, N - M)` (DCASE-2019-style: a mislocalised estimate counts once, as
  a false positive). `amplitude_errors` returns the support-aware total error (SAAE) and the
  matched-only error.
- Noise: isotropic diffuse field with unit power per mode, scaled per realisation so that the
  SNR is relative to the **weakest source**; noise-aware OMP stopping threshold
  (`omp_multi_dict_shared(..., snr=...)`).
- HEALPix grids (nside 2 look grid, nside 16 candidate grid), kernels, dictionaries and the joint
  OMP selection rule.

### Changed
- `healpy` (GPL) is no longer a dependency: the HEALPix geometry used is reimplemented in
  `gspwd._healpix` and verified against healpy 1.19.0 (optional dev-only tests,
  `pip install gspwd[oracle]`).
- Noise is drawn from an explicit `rng` (the research script used an unseeded generator, so its
  noisy runs cannot be reproduced bit-for-bit; the statistics are reproduced).
- `randomscene_rejection`: `max_tries` counts rejected candidates only (it previously counted
  every loop iteration), with a `RuntimeWarning` instead of `print`.
- `selectscores("mean_sq")` is the mean squared modulus (it squared complex values).
- Metrics clip dot products before `arccos` (a coincident estimate used to give NaN).
- `support_aware_amplitude_error` returns the total only; `amplitude_errors` returns the pair.

### Fixed
- Joint OMP indexed the residual update with the wrong signal count when given a single 2-D
  dictionary; division by an all-zero correlation peak no longer produces NaNs.

### Removed
- Dead code, plotting scripts hard-wired to JASP output, the `astropy`, `scikit-learn` and `tqdm`
  imports, `omp_multi_dict_shared_optim` (an unused variant) and the spherical-Slepian kernel
  (`slepian_zonal_coeff`), which the paper does not use. The kernel module now contains only
  the optimised kernel (`zonal_multiobjective_coeff`), the Dirichlet kernel (`maxdfcoeff`) and
  the evaluator `gpulse`: the raised-cosine taper (`kernelcoeff`), `synthkernel` and `gpulsevec`
  were dropped. In `metrics`, the unused `ecr` and the matched-only `ae` were dropped
  (the matched-only error is still returned by `amplitude_errors`).

### Known issues (inherited, documented)
- The multi-order joint OMP renormalises each order's correlations by their maximum. Once one
  order is fitted to machine precision this amplifies rounding noise, so atoms selected after
  that point are not reproducible across machines. Regression tests compare supports on the
  stable prefix.
- The noise-aware stopping threshold uses the number of *signals* as the maximum harmonic order;
  for the single-order estimators this degenerates (see the `snr` parameter docs).
